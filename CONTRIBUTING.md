# Contributing to MegaESP HA

## Before opening a change

- confirm the issue on a real Home Assistant instance if possible
- include the controller firmware version
- include the Home Assistant version
- describe exact reproduction steps

## Pull requests

- keep changes focused
- update `README.md` or `INSTALL.md` if user-visible behavior changes
- update `CHANGELOG.md` for notable user-visible changes
- keep `manifest.json` version aligned with releases
- make sure GitHub Actions are green

## Bug reports

Please include:

- Home Assistant version
- MegaESP integration version
- controller firmware version
- logs or screenshots if available
- exact controller model and network setup if relevant
