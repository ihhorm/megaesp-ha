# Встановлення MegaESP через HACS

## 1. Додати репозиторій у HACS

1. Відкрий `HACS`.
2. Натисни меню `...` у правому верхньому куті.
3. Обери `Custom repositories`.
4. Встав URL:

```text
https://github.com/ihhorm/megaesp-ha
```

5. Вибери тип:

```text
Integration
```

6. Натисни `Add`.

## 2. Встановити інтеграцію

1. Знайди `MegaESP` у HACS.
2. Натисни `Download` або `Install`.
3. Дочекайся завершення встановлення.
4. Перезапусти Home Assistant.

## 3. Додати інтеграцію в Home Assistant

1. Відкрий `Settings -> Devices & services`.
2. Натисни `Add integration`.
3. Знайди `MegaESP`.
4. Введи:
   - IP-адресу контролера
   - порт, зазвичай `80`
   - пароль контролера
   - інтервал опитування
5. Підтвердь налаштування.

## 4. Перевірити сутності

Після додавання перевір:

- `switch.*`
- `sensor.*`
- `number.*`
- `select.*`
- `climate.*`

## 5. Додати термостат на Dashboard

1. Відкрий потрібний Dashboard.
2. Натисни `Edit dashboard`.
3. Додай картку `Thermostat`.
4. Вибери потрібну сутність `climate.megaesp...`.

## 6. Панель MegaESP

Після запуску інтеграція також генерує панель `MegaESP`, де доступні:

- контролери
- сенсори
- регулятори
- переходи `HA` і `Web`

## Якщо щось не з'явилось

- зроби `Ctrl+F5`
- перезавантаж Home Assistant
- перевір, чи контролер доступний по мережі
- перевір пароль і порт
